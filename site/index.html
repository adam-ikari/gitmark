笔记就是 git 仓库里的
markdown 文件

保存就是一次提交，推送与拉取就是同步。两个人同时改到同一段时， 改动不重叠就自动合并；真的合不起来才会停下来找你。 没有私有云，也没有格式转换 —— 笔记离开这个 app 仍然是可读的纯文本。

01三个主张

git 就是存储层，不是附件

没有数据库。整份笔记就是一个 git 仓库，直接在设备上读写。 改动历史免费获得，而且你随时可以离开这个 app， 用任何编辑器修改同一份文件。

安全优先于自动

改动不重叠就自动合并；重叠且无法化解才升级为冲突，而且 整个同步会停下来，不提交也不推送， 直到你处理完为止。

文件始终是纯文本

你的笔记就是普通的 markdown 文件，不存在专有格式。 编辑器只是它的一个视图 —— 排版后的样子存在文件里， 版本历史干净可读，不会被无意义的改动淹没。

02功能

Markdown 渲染

标题、列表、任务列表、引用、表格、嵌套列表与删除线，编辑时所见即所得。

Mermaid 图

流程图、时序图、类图直接写在笔记里，保存后就能看到，不用额外工具。

SVG 图形

矢量图形在任何缩放下都保持锐利，适合示意图与图表。

原生富文本编辑

加粗、斜体、行内代码、删除线、标题层级、列表缩进与任务勾选，都在输入框上方一键切换。

标签与元数据

标题、标签、创建与更新时间写在文件里，方便搜索与整理。

冲突不吞数据

真的合不起来时会把冲突直接标在文件里，任何工具打开都看得见，不会悄悄丢掉任何一边。

04开发进度

已经可用

  • Mermaid 图与 SVG 图形

  • 多设备同步，改动不重叠时自动合并

还在进行

合并引擎与适配层的核心逻辑都有测试覆盖，其中合并引擎会与一个独立的 diff3 实现逐字比对。但没有任何一个环节在真机上跑过 —— 开发这台机器没有可用的模拟器。技术细节、决策记录与开发进度都放在 仓库里。
